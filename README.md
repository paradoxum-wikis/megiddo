# Megiddo

**Megiddo** is a skin swapper for ALTER EGO.

FYI, no, it isn't bannable, since it doesn't modify the Roblox binary, hence, it wouldn't be detected.

## Install

Head to [releases](https://github.com/paradoxum-wikis/megiddo/releases), download the latest version. Run as administrator.

A video guide can be found [here](https://youtu.be/9O91EPH-Kog).
